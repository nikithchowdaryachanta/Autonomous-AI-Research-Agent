# ResearchPilot Submission Runbook

1. Clone/upload the project to GitHub.
2. Create `.env` from `.env.example`.
3. Add `GEMINI_API_KEY`.
4. Add `TAVILY_API_KEY`.
5. Install dependencies.
6. Run `pytest -q`.
7. Run `streamlit run app.py`.
8. Execute a live research question.
9. Verify the report, sources, trace and monitoring metrics.
10. Add the GitHub repository URL to the assessment form.
11. Enter the actual development/testing time.
12. Upload the required architecture diagram, sample trace, write-up and ZIP.
